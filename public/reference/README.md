# Captures à ajouter

Les nouveaux projets utilisent actuellement un visuel temporaire. Ajoute les fichiers suivants, puis remplace la première entrée `images` du projet concerné dans `database/projects.js` par le chemin indiqué :

- `itgreen-os-cover.png` : vue principale du diagnostic. Garde les rubriques demandées floutées.
- `itgreen-intranet-cover.png` : tableau de bord ou parcours stock, sans données client ni identifiants.
- `geodevinette-cover.png` : partie en cours avec Street View et la carte visibles.
- `evolve2d-cover.png` : écran qui montre le mieux la nouvelle direction 2D.
- `trklol-cover.png` : interface ou prototype le plus abouti.
- `zenlol-cover.png` : suivi d’humeur ou écran de session.

Format recommandé : PNG ou WebP, 1600 × 1000 px minimum, sans barre du navigateur. Pour ITGREEN, vérifie le floutage à 100 % avant publication.
